# TrazoPDF 0.3

- Manipulación de imágenes desde Editar PDF: selección, arrastre, esquinas para redimensionar, sustitución y eliminación. Cada operación se dirige a una aparición individual, conservando las demás copias compartidas cuando la estructura admite edición.
- Enlaces web, correo y páginas internas: creación por área, edición, eliminación, listado y apertura explícita.
- Comparación visual en proceso separado, cancelable, con tres vistas, navegación por cambios, zoom sincronizado y exportación del informe ZIP.
- Corrección de las coordenadas de enlaces sobre páginas recortadas y giradas.
- Protección del informe anterior: una nueva comparación exige una carpeta de salida vacía.
- Conservación de líneas al reunir varios segmentos de texto compatibles en un bloque editable.

La comparación revisa la apariencia rasterizada. La edición de imágenes se limita a estructuras compatibles y la edición de texto puede sustituir fuentes. Sigue sin ofrecerse paridad completa con Acrobat Pro; consulta FEATURES.md.
