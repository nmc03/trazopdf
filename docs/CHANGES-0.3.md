# TrazoPDF 0.3

- Image manipulation from Edit PDF: selection, dragging, corner handles for resizing, replacement and deletion. Each operation targets an individual occurrence, preserving other shared copies when the structure allows editing.
- Web, email and internal page links: creation by area, editing, deletion, listing and explicit opening.
- Visual comparison in a separate, cancelable process, with three views, navigation between changes, synchronized zoom and ZIP report export.
- Correction of link coordinates on cropped and rotated pages.
- Protection of the previous report: a new comparison requires an empty output folder.
- Lines are preserved when joining several compatible text segments into one editable block.

The comparison checks the rasterized appearance. Image editing is limited to compatible structures, and text editing may substitute fonts. Full feature parity with commercial PDF editors is not offered; see FEATURES.md.
